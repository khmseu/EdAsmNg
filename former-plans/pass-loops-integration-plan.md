## Plan: Pass Loops and Integration (Phase 8)

Implement the main assembly pass loop system, integrating all previously implemented components (symbol table, directives, opcode processing) into a functional multi-pass assembler following EDASM's architecture.

**Phases (8 sub-phases)**

1. **Phase 8.1: Initialization and Cleanup**
   - **Objective:** Implement session initialization, ZP save/restore, and cleanup routines
   - **Files/Functions to Modify/Create:** src/lib/ei/asm.cpp
   - **Tests to Write:** TEST_InitASM, TEST_SaveRestoreZP, TEST_CleanupSequence
   - **Steps:**
     1. Implement `SaveZP()` - save zero-page workspace to backup area
     2. Implement `RestoreZP()` - restore zero-page from backup
     3. Implement `InitASM()` - clear counters/flags, set defaults, initialize symbol table, initialize relocation dictionary, zero hash table
     4. Implement cleanup sequence - flush buffers, close files, restore state
     5. Set default values: listing on, macros off, conditional assembly off
     6. Initialize `StrtSymT` and `EndSymT` pointers
     7. Initialize `RLDEnd` and other relocation pointers
     8. Zero the `HeaderT` hash table (256 entries)

2. **Phase 8.2: Source Line Reader**
   - **Objective:** Implement source line reading and buffer management
   - **Files/Functions to Modify/Create:** src/lib/ei/asm.cpp
   - **Tests to Write:** TEST_GSrcLin_Memory, TEST_GSrcLin_EOF, TEST_ReadMore_Buffer
   - **Steps:**
     1. Implement `GSrcLin()` - get next source line from memory or disk
     2. Handle memory source mode (read from `SrcP` buffer until `TxtEnd`)
     3. Handle disk source mode (stub for now - Phase 9+)
     4. Handle EOF detection (carry set when done)
     5. Implement `ReadMore()` stub for disk block reading (Phase 9+)
     6. Handle partial-line carry across buffer boundaries
     7. Update `SrcP` to point to current line
     8. Return with carry set/clear to indicate EOF/success

3. **Phase 8.3: Line Processing Helpers**
   - **Objective:** Implement character classification, field navigation, and record advancement
   - **Files/Functions to Modify/Create:** src/lib/ei/asm.cpp
   - **Tests to Write:** TEST_NextRec, TEST_NxtField, TEST_ChrGot, TEST_ChrGet
   - **Steps:**
     1. Implement `NextRec()` - advance `SrcP` to next CR-terminated record
     2. Implement `NxtField()` - advance `SrcP` to start of next field (first non-space)
     3. Implement `ChrGot()` - get character at `SrcP[Y]`, classify, uppercase
     4. Implement `ChrGet()` - get and advance (Y++), classify, uppercase
     5. Use existing character classification tables (already present)
     6. Handle CR detection for end of line
     7. Handle space/delimiter classification
     8. Return character type flags in appropriate CPU flag bits

4. **Phase 8.4: Pass 1 Loop (Symbol Collection)**
   - **Objective:** Implement Pass 1 main loop for symbol table building
   - **Files/Functions to Modify/Create:** src/lib/ei/asm.cpp
   - **Tests to Write:** TEST_DoPass1_SimpleLabel, TEST_DoPass1_MultipleLabels, TEST_Pass1_PCAdvancement
   - **Steps:**
     1. Implement `DoPass1()` entry point
     2. Set `PassNbr = 0` (Pass 1)
     3. Open/reopen source to beginning
     4. Implement `Pass1Lup` main loop label
     5. Call `GSrcLin()` to fetch next line
     6. If EOF (carry set), exit Pass 1
     7. Clear `ErrorF` for new line
     8. Parse label field (if present) - call `FindSym` or `AddNode`
     9. If label found/created, set its value to current `PC`
     10. Call `HndlMnem()` to process mnemonic/directive
     11. Call `GInstLen()` to compute instruction length (stub for now)
     12. Call `AdvPC()` to advance program counter
     13. Call `NextRec()` and loop back to `Pass1Lup`
     14. Exit when EOF reached

5. **Phase 8.5: Pass 2 Loop (Code Generation)**
   - **Objective:** Implement Pass 2 main loop for object code generation and listing
   - **Files/Functions to Modify/Create:** src/lib/ei/asm.cpp
   - **Tests to Write:** TEST_DoPass2_SimpleInstruction, TEST_Pass2_Listing, TEST_Pass2_ObjectCode
   - **Steps:**
     1. Implement `DoPass2()` entry point
     2. Set `PassNbr = 1` (Pass 2)
     3. Turn listing on (`ListingF` MSB set)
     4. Reopen source to beginning
     5. Implement `Pass2Lup` main loop label
     6. Call `GSrcLin()` to fetch next line
     7. If EOF (carry set), exit Pass 2
     8. Clear `ErrorF` for new line
     9. Skip label field parsing (symbols already defined in Pass 1)
     10. Call `HndlMnem()` to process mnemonic/directive
     11. Generate machine code via addressing mode/opcode logic
     12. Call `StorGMC()` to store generated bytes
     13. Call `PrtAsmLn()` to print listing line (if enabled)
     14. Call `AdvPC()` to advance program counter
     15. Call `NextRec()` and loop back to `Pass2Lup`
     16. Exit when EOF reached

6. **Phase 8.6: Main Session Driver**
   - **Objective:** Implement top-level ExecAsm session driver
   - **Files/Functions to Modify/Create:** src/lib/ei/asm.cpp
   - **Tests to Write:** TEST_ExecAsm_SimpleProgram, TEST_ExecAsm_WithSymbols, TEST_ExecAsm_WithErrors
   - **Steps:**
     1. Implement `ExecAsm()` session driver function
     2. Call `SaveZP()` to preserve workspace
     3. Set up interrupt vectors (stub for now)
     4. Call `InitASM()` to initialize assembler state
     5. Call `DoPass1()` to perform Pass 1
     6. Call `DoPass2()` to perform Pass 2
     7. Check `CancelF` flag for early abort
     8. Call `DoPass3()` (symbol listing) if enabled
     9. Call `PrSummry()` to print error summary (stub)
     10. Call `PrtEndAsm()` to print end message (stub)
     11. Call cleanup/flush routines
     12. Call `RestoreZP()` to restore workspace
     13. Return to caller (EI)

7. **Phase 8.7: PC and Object Code Management**
   - **Objective:** Implement AdvPC, GInstLen, StorGMC, and StorByt
   - **Files/Functions to Modify/Create:** src/lib/ei/asm.cpp
   - **Tests to Write:** TEST_AdvPC_Simple, TEST_GInstLen_Various, TEST_StorGMC_Memory, TEST_StorByt_Limits
   - **Steps:**
     1. Implement `AdvPC()` - advance `PC` by instruction length
     2. Handle 16-bit addition with carry
     3. Check for PC overflow (wrap at $10000)
     4. In Pass 2, also advance `ObjPC` when generating code
     5. Implement `GInstLen()` stub - compute instruction length from addressing mode
     6. Implement `StorGMC()` - store GMC buffer contents to memory or disk
     7. Check `GenF` flag: N=suppress, V=disk, V=0=memory
     8. If memory mode, write bytes to `(ObjPC)`
     9. If disk mode, call `Wr1Byte()` stub (Phase 9+)
     10. Implement `StorByt()` - store single byte with limit checks
     11. Check memory bounds (don't overwrite system areas)
     12. Advance `ObjPC` after each byte stored

8. **Phase 8.8: Listing Output Stubs**
   - **Objective:** Stub listing output routines for integration testing
   - **Files/Functions to Modify/Create:** src/lib/ei/asm.cpp
   - **Tests to Write:** TEST_PrtAsmLn_Stub, TEST_RVLsting_Check
   - **Steps:**
     1. Implement `RVLsting()` - check if listing should be generated
     2. Check `ListingF` MSB (listing enabled)
     3. Check `ErrorF` (list lines with errors)
     4. Check conditional assembly flags (stub)
     5. Check macro expansion flags (stub)
     6. Return result in carry or zero flag
     7. Implement `PrtAsmLn()` stub - print assembly line
     8. Call `ListCode()` stub - print PC and machine bytes
     9. Call `LstSrcLn()` stub - print source text
     10. For now, just set flags indicating "would print"
     11. Full listing output implementation deferred to Phase 9+
